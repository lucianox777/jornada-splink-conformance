# Jornada × Splink — conferência externa

Runner **externo**, offline e exclusivamente sintético para confrontar estados do comparador C# da Jornada com Splink 4.0.17 (DuckDB). Este repositório é independente: **não** entra no build, deploy nem pipeline da [Jornada](https://github.com/lucianox777/Jornada).

A primeira entrega versiona o runner e os testes em PR. Os replays e resultados volumosos permanecem fora do Git, sob SHA-256 documentado no repositório Jornada. Esta ferramenta **não** demonstra calibração estatística independente das probabilidades `u`; essa conferência é um trabalho separado da [issue #506](https://github.com/lucianox777/Jornada/issues/506).

Não use dados pessoais, credenciais, exportações operacionais ou qualquer origem diferente dos pares sintéticos do contrato `JORNADA_SPLINK_IBGE_U_REPLAY_V1`.
